Before recording anything

Use anonymous codes, not names, emails, usernames, or other personal identifiers. Real participants require independently documented informed consent before any observation is collected. Consent records must be kept outside this public repository.

Never run untrusted generated code on a personal or production computer. This page does not run code or score solutions.

What the record can prove

A JSON export preserves what someone entered and ties it to a fixed task-pack hash. It does not prove a person was present, that consent occurred, that time was accurately measured, or that scores were independently verified.
